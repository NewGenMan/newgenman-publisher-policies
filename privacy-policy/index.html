Privacy Policy

NewGenMan Publisher  ·  Effective date: 3 June 2026  ·  Last updated: 3 June 2026

1. About This Application

NewGenMan Publisher ("the App") is a personal developer tool owned and operated by NewGenMan (makchunhin@gmail.com). The App uses the TikTok Content Posting API to upload short-form video content to the developer's own TikTok account (@newgenman_hk). It is not a consumer-facing product and is not available to any third party.

2. Who This Policy Applies To

The App has a single user: the developer. No third-party end users authenticate with or use this App. Accordingly, no personal data belonging to third parties is collected, processed, or stored.

3. Data We Access and Use

To publish content via the TikTok Content Posting API, the App uses the following:

  • TikTok OAuth access token — obtained via the developer's own TikTok account authorisation. Stored locally on the developer's machine only. Never shared.
  • Video files — MP4 files created by the developer, uploaded directly to TikTok servers. Not stored by the App beyond the local filesystem.
  • Caption text — written by the developer and passed as part of the publish request. Not stored externally.

4. Data We Do Not Collect

The App does not collect, store, or transmit any of the following:

  • Personal data of any TikTok viewers or users
  • Analytics, tracking, or behavioural data
  • Cookies or device identifiers from third parties
  • Any data beyond what is required to complete a video publish request

5. Third-Party Services

The App communicates exclusively with the TikTok for Developers API (open.tiktokapis.com). TikTok's own privacy policy governs how TikTok handles data: tiktok.com/legal/privacy-policy.

6. Data Security

All API credentials and tokens are stored locally on the developer's machine and are never transmitted to any server other than TikTok's official API endpoints. Access tokens expire per TikTok's token lifecycle policy.

7. Changes to This Policy

If the scope or nature of the App changes materially, this policy will be updated. The effective date at the top of this page reflects the most recent revision.

8. Contact

Questions about this privacy policy can be directed to: makchunhin@gmail.com
